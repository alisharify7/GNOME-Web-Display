# GNOME Web Display v2.0.1

## MediaMTX startup fix

This patch release fixes `open /mediamtx.yml: permission denied` when an install
created under a restrictive umask is used with a Docker user namespace or similar
permission boundary.

The launcher now makes only the bundled, public MediaMTX YAML readable before
mounting it read-only. Docker capabilities remain dropped, `no-new-privileges`
remains enabled, and the private TCP port mappings are unchanged.

Run the installer again and select `v2`, `v2.0.1`, or `latest`.
